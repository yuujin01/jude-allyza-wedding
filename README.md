# Jude & Allyza modular wedding invitation

Upload the contents of this folder to the root of the existing GitHub Pages repository, replacing `index.html`, `style.css`, and `app.js`. Upload the `assets` folder and its contents. Keep any existing Apps Script files if still needed.

Features: independently laid-out invitation sections inspired by the supplied watercolor reference; responsive layout; Philippine-time countdown to December 3, 2026 at 11:00 AM; one (non-duplicated) attendance radio group; guest-name suggestions and seat allocations from the provided guest-list details.

Important: RSVP responses are not persisted or sent to a spreadsheet yet. A backend/Google Sheets connection must be configured separately before guests use it for actual confirmations.
