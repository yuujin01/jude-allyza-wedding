# Jude & Allyza — Exact Reference Invitation

This version uses the supplied full-page 1024 × 1536 watercolor invitation artwork as the visual base. The artwork is not recreated or rearranged; transparent clickable areas are positioned over the original image.

## Files
- `index.html` — invitation image and interactive overlay elements
- `style.css` — responsive image sizing and overlay positions
- `app.js` — live countdown, favorite toggle, and RSVP form interaction
- `assets/invitation-reference.png` — supplied full invitation artwork

## Publish with GitHub Pages
Keep `index.html`, `style.css`, `app.js`, and the `assets` folder in the repository root. GitHub Pages should use `main` and `/(root)`.

## Important RSVP note
The RSVP overlay currently collects a name and attendance choice in the browser and displays a message. It does not yet save responses to a database or Google Sheet. A secure RSVP backend and guest verification must be configured separately before using it for real guest responses.
